# BELABOX documentation images

The current documentation uses prototype enclosure photos. These are temporary and will be replaced with final photographs after all hardware is installed.

Important mapping for the current prototype set:

- `belabox-prototype-overview.jpg` - overall enclosure/build view; the newest full-build photo should be used for the next replacement
- `belabox-prototype-io-panel.jpg` - top I/O, antenna and port layout
- `belabox-prototype-cooling.jpg` - enclosure cooling fan
- `belabox-prototype-led-panel.jpg` - four physical status LEDs
- `belabox-prototype-gpio-wiring.jpg` - status-LED GPIO connector/wiring
- planned `belabox-prototype-board.jpg` - top-down view of the complete ROCK 5B+ board inside the enclosure

Photo identification clarification:

- the latest close-up with the black 5-wire connector at the ROCK 5B+ GPIO header is the **status-LED wiring**
- the latest top-down image is the **complete board / internal hardware overview**
- the latest angled enclosure image is the **new full-build overview**
- the separate earlier close-up showing wires beside the heatsink/cooler is the **fan wiring**, not the LED harness

Final enclosure photos will replace the prototype set when the remaining hardware is installed.
