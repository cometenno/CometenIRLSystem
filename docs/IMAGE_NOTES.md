# BELABOX documentation images

The current documentation uses prototype enclosure photos. These are temporary and will be replaced with final photographs after all hardware is installed.

Important mapping for the current prototype set:

- `belabox-prototype-overview.jpg` - overall enclosure/build view
- `belabox-prototype-io-panel.jpg` - top I/O, antenna and port layout
- `belabox-prototype-cooling.jpg` - enclosure cooling fan
- `belabox-prototype-led-panel.jpg` - four physical status LEDs
- `belabox-prototype-gpio-wiring.jpg` - status-LED GPIO connector/wiring only

Do not use a photo of the fan wiring as GPIO/status-LED wiring. The earlier close-up with a hand holding wires near the heatsink shows the fan wiring and is not the status-LED harness.
